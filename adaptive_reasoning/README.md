# adaptive_reasoning/ — SignWay Adaptive Reasoning Scheduler (clean rebuild)

One file per term of the gate equation. Every file is pure enough to test on a
laptop with no robot, no GPU and no calibrated weights. Weights and calibrations
are *data* in `calib/` and `goals/`, never constants in code.

```
adaptive_reasoning/
├── README.md                  ← this file
├── config.py                  (later) dataclass of run-time knobs: k, K, tau, model id. No weights.
├── evidence/
│   ├── expand_goal.py         ✅      V_g generated by ONE blind LLM call per goal → goals/<g>.json with provenance meta
│   ├── relevance.py           [1] ✅  "Is this plate about my goal?"  R = max(R_struct, R_sem)
│   ├── resolve.py             [1b] ✅ "Can I read the goal's arrow myself?" → fast path, lowers necessity N_t
│   ├── features.py            [2] ✅  plate crop → φ (height, sharpness, ocr_conf, completeness, foreshortening, agreement)
│   ├── detect.py              [3] ✅  frame → plates: OcrEngine protocol (DocTREngine lazy) + pure clustering; arrows from OCR text
│   ├── legibility.py          [4] ✅  ℓ = σ(w·φ) on standardized features; loads calib/w.json, warns if UNCALIBRATED
│   └── buffer.py              [4b] ✅ plate tracks across frames: exact/fuzzy/IoU association, agreement, ageing
├── memory.py                  [5] ✅  M_g: plates already consumed for goal g (exact keys; gate returns updates, never mutates)
├── gate.py                    [6] ✅  N_t · max R·ℓ ≥ τ + FSM (NO_SIGN / ARMED / PENDING / DECIDED). Pure. Fast path via resolve.
├── replay/
│   ├── figstyle.py            ✅      one visual language: ICRA sizes, palette (incl. gate-state colors), save()+npz
│   ├── validate_annotations.py ✅     T0 gate: protocol checks on ar_extra.csv using the real relevance/resolve
│   ├── fig_margin.py          ✅      Fig ar-margin (E4) from ar_extra.csv; --latency once E3 lands
│   ├── timeline.py            ✅      Fig ar-timeline; runs the REAL gate; --demo until E1 npz exists
│   ├── dump_features.py       [7] ✅  E1: RosbagSource/ImageDirSource → detect→buffer→R/φ/ℓ → npz+jsonl (pipeline smoke-tested)
│   ├── baselines.py           [8] ✅  Always/Periodic/Reactive/SuffOnly/RelOnly/UncertaintyGate — subclasses of the real gate
│   ├── sweep.py               [8] ✅  E5: τ sweep + baselines → table_main.md/.tex + tradeoff fig (--oracle now; cached-VLM with E2)
│   ├── calibrate.py           (E2) ✅ numpy IRLS logistic + reliability/|w| fig; --synthetic smoke passes; VLM labels once crops stored
│   └── timeline.py            (E6)    Fig timeline
├── reasoner.py                [9]     VLM client, JSON schema, response cache keyed (bag, frame, crop-hash)
├── server.py                  [10]    Flask wrapper for the Jetson — plumbing only
├── calib/                     w.json, sem.json   (outputs of T6; absent = UNCALIBRATED warnings)
├── goals/                     <goal>.json descriptor sets V_g (one LLM call per goal, cached)
└── tests/                     one test file per module
```

## Rules
1. A file is done when it has tests that pass **and** you can say what it does in two sentences.
2. The old code is read, never imported.
3. Nothing that should be empirical is a literal in code. If you are about to type `0.6`, stop and
   ask which ticket produces that number.
4. `gate.py` and the baselines share one interface so replay and live run the same bytes.

## Run
```bash
cd <repo>
python -m pytest adaptive_reasoning/tests -q
python -m adaptive_reasoning.evidence.relevance "6-201 to 6-250 > | Main Elevators <" 6-217
```

## First run on the bags (MSI, env `ar`)
```bash
pip install rosbags   # pure python; docTR already in `ar`
python -m adaptive_reasoning.replay.validate_annotations annotations/ar_extra.csv --goals-dir adaptive_reasoning/goals
python -m adaptive_reasoning.replay.dump_features --csv annotations/ar_extra.csv \
    --bags-root ~/SignWay/ros2_bags --out $SCRATCH/ar_replay --only rosbag2-keller-t1
# sanity: real timeline figure for t1
python -m adaptive_reasoning.replay.timeline --npz $SCRATCH/ar_replay/rosbag2-keller-t1.npz --tau 0.55 --fps 10 --out figs/t1_timeline
# then all bags (drop --only), then the dry sweep:
python -m adaptive_reasoning.replay.sweep --dumps $SCRATCH/ar_replay --csv annotations/ar_extra.csv --oracle --tau-star 0.55 --out figs/sweep
```
